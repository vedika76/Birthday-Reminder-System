# Birthday Reminder System

A desktop-based application built using Java Swing, JDBC, and MySQL to manage birthday records and track upcoming birthdays.

## Features

- Add, edit and delete birthday records
- Search birthdays by name or relationship
- Automatic age calculation
- Calculate days remaining until the next birthday
- View today's and upcoming birthdays
- Add relationship and notes
- MySQL database integration

## Technologies Used

- Java
- Java Swing & AWT
- JDBC
- MySQL

## How to Run

1. Open the project in IntelliJ IDEA or NetBeans.
2. Add MySQL Connector/J to the project.
3. Make sure MySQL Server is running.
4. Configure the database username and password in `MainFrame.java`.
5. Run `MainFrame.java`.

## Date Format

Enter birthdays in the following format:

`YYYY-MM-DD`

Example: `2006-12-07`
